# OSEK-Remastered

Это неофициальный клиент Открытого Социально-Экономического Колледжа [sdo.i-spo.ru](https://sdo.i-spo.ru/) для Windows 10/11. Курсы, учебный план, уведомления, сообщения, календарь, вебинары, новости, профиль, зачётная книжка, учебный график и таблицы раздела документов имеют собственный интерфейс. Лекции, видео, страницы электронных книг и PDF зачётной книжки открываются во встроенном просмотре.

Имя и фотография в боковой панели берутся из текущей учётной записи ОСЭК. При первом входе пароль сохраняется в Windows Credential Manager после успешной авторизации; при следующих запусках приложение использует сохранённую сессию или выполняет вход автоматически.

Чтобы удалить приложение, закройте его через значок в трее и удалите распакованную папку. Локальная сессия находится в `%APPDATA%\SDO-Reborn`, сохранённые данные входа — в Windows Credential Manager под именем `SDO-Reborn`.

## Приватность и безопасность

- Учётные данные отправляются только на `sdo.i-spo.ru` по HTTPS. Пароль хранится в Windows Credential Manager через `keyring`; в репозитории, кэше и логах его нет.
- У приложения нет аналитики и телеметрии. Сервер ОСЭК отдаёт содержимое и файлы. Для видео используется также источник `media2.sdo.support`, указанный в материалах колледжа.
- В распакованной папке присутствует диагностический логирующий журнал: он сохраняет типы действий, переходы и ошибки без паролей, текста сообщений и параметры ссылок. Файл остаётся на компьютере пользователя и ограничен 2 МБ на запись с двумя резервными копиями, находится по адресу `%LOCALAPPDATA%\ОСЭК-Remastered\events.txt`. Если у вас есть ошибки или другая проблема, можете прислать этот файл мне в телеграмм @Play_in_Spirits

> [!WARNING]
> Это неофициальный клиент, он не был одобрен администрацией колледжа (никто у них просто не спрашивал). Пользуйтесь им на свой риск и в рамках правил колледжа. Могут быть ошибки.
