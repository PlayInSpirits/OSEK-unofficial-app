# ОСЭК-Remastered

Неофициальный клиент СДО [sdo.i-spo.ru](https://sdo.i-spo.ru/) для Windows 10/11. Страницы СДО открываются в основном окне приложения с собственной боковой навигацией. Курсы, сообщения, уведомления, файлы, видео и формы заданий работают через штатный сайт внутри этого окна.

> Предварительная версия. Раздел «Почтовый ящик» пока ведёт к сообщениям Moodle: отдельный адрес почты на сайте не найден. Доступность сдачи работ определяется самим сайтом колледжа.

## Скачать и запустить

Откройте [Releases](https://github.com/PlayInSpirits/SDO-Reborn/releases), скачайте `OSEK-Remastered-Windows.zip`, распакуйте **всю папку** и запустите `ОСЭК-Remastered.exe` внутри неё. Файлы рядом с `.exe` нужны для работы и ускоряют повторный запуск. Для проверки целостности сравните SHA-256 файла со значением в `SHA256.txt` рядом с релизом. Нужен установленный Microsoft Edge WebView2 Runtime. Приложение использует сохранённый вход Windows Credential Manager, если он есть, и хранит сессию встроенного браузера в `%APPDATA%\SDO-Reborn`.

Чтобы удалить приложение, закройте его через значок в трее и удалите распакованную папку. Локальная сессия находится в `%APPDATA%\SDO-Reborn`, сохранённые данные входа — в Windows Credential Manager под именем `SDO-Reborn`.

## Сборка из исходников

На Windows с Python 3.11:

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python run.py
```

GitHub Actions собирает `ОСЭК-Remastered.exe` с файлами среды через PyInstaller, публикует ZIP как предварительный релиз и прикладывает `SHA256.txt`. Код сборки виден в `.github/workflows/windows.yml`.

## Приватность и безопасность

- Учётные данные отправляются только на `sdo.i-spo.ru` по HTTPS. Пароль хранится в Windows Credential Manager через `keyring`; в репозитории, кэше и логах его нет.
- У приложения нет аналитики и телеметрии. Собственные HTTP-запросы направлены только к СДО. Во встроенном окне показывается сам сайт колледжа, который может загружать свои ресурсы.
- Приложение не отправляет задания автоматически: это делает пользователь на штатной странице задания внутри окна.
- Сохранённые HTML-страницы в `pages/` содержат личные данные и исключены из Git. Тесты используют обезличенные примеры.

Это неофициальный клиент. Пользуйтесь им на свой риск и в рамках правил колледжа.

## Диагностика

`python diagnostics/check_sdo.py` проверяет вход и три AJAX-метода. Пароль вводится только в консоли и не сохраняется. Результаты диагностики не следует публиковать вместе с логином или данными с сайта.
