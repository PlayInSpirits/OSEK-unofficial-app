# SDO-Reborn

Неофициальный клиент СДО [sdo.i-spo.ru](https://sdo.i-spo.ru/) для Windows 10/11. Показывает курсы, ближайшие события календаря, сроки и уведомления. Задания открываются **во встроенном окне настоящего сайта**: файл выбирается и отправляется через штатную форму СДО. Перед окончательной отправкой проверяйте статус и выбранный файл на странице задания.

> Предварительная версия. На проверенной установке СДО AJAX-методы для курсов, сроков и уведомлений работают. Если сервер их отключит, эти разделы могут быть пустыми; курсы, календарь и переход к заданиям используют HTML-страницы.

## Скачать и запустить

Откройте [Releases](https://github.com/PlayInSpirits/SDO-Reborn/releases), скачайте `SDO-Reborn.exe` и запустите. Для проверки целостности сравните SHA-256 файла со значением в `SHA256.txt` рядом с релизом. Нужен установленный Microsoft Edge WebView2 Runtime. При первом запуске введите учётные данные СДО; затем вход выполняется автоматически.

Чтобы удалить приложение, закройте его через значок в трее и удалите `.exe`. При необходимости отключите автозагрузку в настройках перед удалением. Локальные данные находятся в `%APPDATA%\SDO-Reborn`, сохранённые данные входа — в Windows Credential Manager под именем `SDO-Reborn`.

## Сборка из исходников

На Windows с Python 3.11:

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python run.py
```

GitHub Actions собирает один `SDO-Reborn.exe` через PyInstaller, публикует его как предварительный релиз и прикладывает `SHA256.txt`. Код сборки виден в `.github/workflows/windows.yml`.

## Приватность и безопасность

- Учётные данные отправляются только на `sdo.i-spo.ru` по HTTPS. Пароль хранится в Windows Credential Manager через `keyring`; в репозитории, кэше и логах его нет.
- У приложения нет аналитики и телеметрии. Собственные HTTP-запросы направлены только к СДО. Во встроенном окне показывается сам сайт колледжа, который может загружать свои ресурсы.
- Приложение не отправляет задания автоматически: это делает пользователь на штатной странице задания.
- Сохранённые HTML-страницы в `pages/` содержат личные данные и исключены из Git. Тесты используют обезличенные примеры.

Это неофициальный клиент. Пользуйтесь им на свой риск и в рамках правил колледжа.

## Диагностика

`python diagnostics/check_sdo.py` проверяет вход и три AJAX-метода. Пароль вводится только в консоли и не сохраняется. Результаты диагностики не следует публиковать вместе с логином или данными с сайта.
