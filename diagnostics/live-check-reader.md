# Проверка встроенного просмотра и навигации

Проверки выполнены в Windows через интерфейс WebView2 с данными действующей учётной записи СДО. Файлы тестов остались прежними.

| Сценарий | Результат |
| --- | --- |
| Раскрыть каждую из двух программ на «Главной» и выбрать её зачётку | Выбран соответствующий пункт списка. Первая программа показывает 4 таблицы, вторая 14. |
| Открыть PDF второй программы и перейти на следующую страницу | PDF отрисован внутри приложения, счётчик меняется с 1 / 8 на 2 / 8. |
| Выбрать названия двух HTML-лекций | Список тем скрыт. Отображены 24 и 51 абзац. Адрес окна остался локальным в обоих случаях. |
| Выбрать две видеоверсии и начать воспроизведение | Позиция воспроизведения сдвинулась в обоих случаях. Ширина кадра 1920 пикселей, адрес окна локальный. |
| Открыть две электронные книги | СДО вернула 15 и 17 страниц. Первая страница каждой книги загрузилась как изображение шириной 875 пикселей. |
| Открыть два события в «Календаре» | Для каждого открылись два блока с подробностями. Кнопка «Назад» вернула список. |
| Открыть два вебинара и переключить месяц | Оба события открылись с подробностями внутри клиента. На предыдущем месяце отображены 18 событий. |
| Открыть «Учебный график» основной программы | Показаны три таблицы. В сетке 52 недельные колонки, для которых проверены отсутствие переноса и доступность горизонтальной прокрутки. |
| Открыть «Документы и платежи» основной программы | Показаны две таблицы. Столбцы «Квитанции», «Чеки об оплате» и «Оплата online» отсутствуют. |
| Сверить мини-профиль и страницу профиля | В мини-профиле загрузилось фото 512 × 512 и отображается формат «Имя Ф.О.». В профиле одно фото, четыре уникальных поля, две программы. |

Интерактивные формы СДО, в том числе отправка работ и прохождение тестов, остаются вне встроенного просмотра. Плеер показывает видеоматериалы курса. Подключение к прямой трансляции вебинара в этой проверке не выполнялось.
