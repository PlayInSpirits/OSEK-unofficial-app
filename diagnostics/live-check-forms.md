# Проверка работ, календаря и записей вебинаров

Прогоны выполнены в Windows с действующими данными СДО. Файлы тестов и README остались без изменений.

| Сценарий | Фактический результат |
| --- | --- |
| Открыть «Историю России» из «Курсов» | В списке 33 пункта. Перед списком появились 6 блоков, в том числе аннотация и минимальный проходной балл. Из разметки СДО показаны 15 статусов выполнения. |
| Открыть две самостоятельные работы по истории | У обеих есть кнопки «Прикрепить файл» и «Сохранить». СДО вернула ограничение в один файл на работу. |
| Загрузить временный TXT в области вложений этих двух работ | Обе загрузки получили от СДО подтверждение с именем файла. Проверка использовала временные черновики. Формы сдачи работ не отправлялись. |
| Открыть два теста по истории и «Задание 1» по финансовой грамотности | СДО предоставила форму старта для каждого материала. В «Задании 1» интерфейс показал «Начать попытку». Зачётная попытка не запускалась. |
| Открыть «Задать вопрос» в двух разных курсах | В курсе информационных технологий СДО предоставила данные преподавателя, появилось поле вопроса. В истории сервис вернул пустой список получателей. Для этого случая клиент показывает причину. Тестовые вопросы не отправлялись. |
| Открыть два события и нажать на дату из их карточек | В обоих случаях появился отдельный экран дня с 8 событиями. Возврат открывает карточку, затем список. |
| Пролистать каталог вебинаров | Сервер вернул 12 + 12 + 12 + 12 + 6 карточек, всего 54 уникальные записи. Поиск известного названия вернул одну карточку, запрос без совпадений вернул пустой список. |
| Открыть первые две записи | У обеих видео вернуло HTTP 206 и тип `video/mp4`, презентации отрисованы PDF движком, по 26 страниц. Первая запись также воспроизвелась в окне клиента. |

Открытие формы и передача файла в черновик проверены отдельно от сдачи реальной работы. Завершение зачётного теста и подключение к прямой трансляции не проверялись.
